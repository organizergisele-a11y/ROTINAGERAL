# ROTINA GERAL

Aplicativo instalável (PWA) de rotinas de organização, limpeza e manutenção residencial.
Gisele Oliveira · Personal Organizer de Alto Padrão.

## Arquivos
- `index.html` — o aplicativo completo.
- `manifest.webmanifest`, `sw.js` — instalação na tela inicial e funcionamento sem internet.
- `icons/` — ícones do app e logos.
- `netlify.toml` — publica a raiz do repositório no Netlify, sem etapa de build.

## Publicar no Netlify
Add new project › Import an existing project › GitHub › este repositório.
Build command: vazio · Publish directory: `.` (o `netlify.toml` já define isso).

## Atualizar
Envie os arquivos novos por "Add file › Upload files" e clique em "Commit changes".
O Netlify publica a nova versão automaticamente.
