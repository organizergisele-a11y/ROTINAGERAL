# ROTINA GERAL

Aplicativo instalável (PWA) de rotinas de organização, limpeza e manutenção residencial.
Gisele Oliveira · Personal Organizer de Alto Padrão.

Todos os arquivos ficam na raiz, sem pastas. As logos estão embutidas no `index.html`;
os PNG são os ícones da tela inicial e da aba do navegador.
`netlify.toml` publica a raiz do repositório no Netlify, sem etapa de build.

Para atualizar: "Add file › Upload files", selecionar os arquivos novos e "Commit changes".
